# PasswordManager

安全で暗号化されたパスワード管理アプリケーションです。マスターパスワード1つであらゆるパスワードを管理できます。

## 機能

- **マスターパスワード保護**: 1つのパスワードですべてのデータを暗号化・保護
- **AES-256 暗号化**: 業界標準の暗号化方式でデータを安全に保存
- **CSV インポート/エクスポート**: テキストファイルからのデータ移行に対応
- **パスワードマスキング**: パスワードの表示/非表示を切り替え可能
- **UI設定の自動保存**: ウィンドウサイズ、位置、列幅を自動保存

## インストール

### 必須環境
- Windows 10 以上
- .NET 10.0 以上

### インストール手順

1. リポジトリをクローン
```bash
git clone https://github.com/tkizawa/PasswordManager.git
cd PasswordManagerApp
```

2. プロジェクトをビルド
```bash
dotnet build
```

3. アプリを実行
```bash
dotnet run
```

### インストーラー（EXE形式）の作成手順

本アプリは、**Inno Setup 6** を使用して Windows 用の `.exe` インストーラーを作成することができます。

#### 前提条件
- **Inno Setup 6** がインストールされていること。（インストールされていない場合は、PowerShell 等で `winget install JRSoftware.InnoSetup` を実行してインストールできます）

#### ビルド手順
1. `Installer` ディレクトリへ移動します。
2. PowerShell でビルドスクリプトを実行します。
```powershell
cd Installer
powershell .\build-installer.ps1
```
3. ビルドに成功すると、`Installer\Output\PasswordManagerAppSetup.exe` にインストーラーが生成されます。
   - インストールを実行すると、アプリは `C:\Program Files\PasswordManagerApp` に配置され、スタートメニューに登録されます。

## 使い方

### 起動時

アプリを初めて起動すると、マスターパスワード設定ダイアログが表示されます。

- **新規作成時**: 新しいマスターパスワードを入力して確認
- **既存データ読み込み時**: 登録済みのマスターパスワードを入力

### パスワードの登録

1. 右側パネルに以下を入力
   - **名前**: サービス名など（例：Gmail）
   - **アカウント名**: メールアドレスやユーザー名
   - **パスワード**: パスワード

2. **Add** ボタンをクリック
3. リストに追加されます

### パスワードの編集

1. リストからエントリを選択
2. 右側パネルで情報を修正
3. **Update** ボタンをクリック

### パスワードの削除

1. リストからエントリを選択
2. **削除** ボタンをクリック
3. 確認ダイアログで「はい」をクリック

### パスワードのコピー

1. リストからエントリを選択
2. **コピー** ボタンをクリック
3. クリップボードにコピーされます

### インポート（CSV）

1. **インポート** ボタンをクリック
2. 以下の形式のテキストファイルを選択
   ```
   名前,アカウント名,パスワード
   Gmail,user@gmail.com,password123
   ```

### エクスポート（CSV）

1. **エクスポート** ボタンをクリック
2. 保存先を選択して保存
3. CSV 形式でダウンロード

### パスワード表示設定

- **リストでパスワードを表示** チェックボックス
  - オン：リストにパスワードが表示される
  - オフ：パスワードが「●●●」でマスクされる

## ファイル保存場所

アプリケーション設定とデータは以下に保存されます：

- **パスワードファイル**: `%LOCALAPPDATA%\PasswordManagerApp\passwords.json`
- **UI設定**: `%LOCALAPPDATA%\PasswordManagerApp\settings.json`

## マスターパスワードを忘れた場合

残念ながら、マスターパスワードは復旧できません。以下の手順で新規に開始できます。

1. アプリを終了
2. 以下のファイルを削除
   - `%LOCALAPPDATA%\PasswordManagerApp\passwords.json`
3. アプリを再起動
4. 新しいマスターパスワードを設定

**注意**: この操作により既存のすべてのパスワードデータが削除されます。

## 入力エラーが表示される場合

マスターパスワード入力後に「入力エラー」が出ても、アプリは使用可能です。以下の原因が考えられます。

- パスワードが6文字未満（新規作成時）
- 確認用パスワードが一致していない（新規作成時）
- 入力したパスワードが正しくない（既存データ読み込み時）

正しいパスワードを再度入力してください。

## セキュリティについて

- マスターパスワードは平文では保存されません
- すべてのパスワードは AES-256 で暗号化されます
- 暗号化キーは PBKDF2（10,000 イテレーション）で生成されます
- パスワードハッシュには SHA-256 を使用

## トラブルシューティング

### ウィンドウサイズが保存されていない
→ `settings.json` を削除して再起動してください

### パスワードが読み込めない
→ `passwords.json` が破損している可能性があります。バックアップから復元してください

### マスターパスワードが間違っていると言われる
→ Caps Lock がオンになっていないか確認してください。パスワードは大文字小文字を区別します。
